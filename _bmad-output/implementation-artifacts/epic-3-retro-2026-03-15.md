## Challenges

- **TestClock gotcha in 2/4 stories**: `@effect/vitest` uses TestClock which does NOT advance `Date.now()`. Story 3.2: concurrency test timed out → fixed with `Effect.yieldNow()`. Story 3.4: circuit breaker uses `Date.now()` → fixed with `realDelay(25)` instead of `Effect.sleep`. Ad-hoc workarounds each time — not yet documented.
- **Missing `_tag` assertion test in Story 3.4**: Project Lead had to intervene to add a test asserting exact `_tag` values for the circuit breaker. Would likely have been caught in code review, but should have been in the spec from the start.
- **`Stream.mapEffect` unbounded concurrency terminates on first element failure**: Non-obvious Effect behavior discovered in Story 3.4. Forced integration test adjustment (threshold 2→1). Behavior is correct but surprising.

## Key Insights

1. **TestClock vs `Date.now()` is a recurring trap**: Must be documented in `project-context.md` so dev agents don't rediscover it on every story that involves real-time delays.
2. **`_tag` assertions must be systematic**: Every story that extends a discriminated union (`UploadError`, `UploadEvent`) should explicitly include `_tag` value assertions in its subtasks.
3. **The improvement cycle works**: 3 consecutive epics with 100% delivery, action items from previous retros consistently honored when embedded in story specs (Task 0 pattern).
4. **Code review remains a critical safety net**: Story 3.2 review found 2 real issues that would have caused downstream problems.
