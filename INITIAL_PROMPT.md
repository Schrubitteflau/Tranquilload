Le dossier @smoothmultipartupload/ contient une structure de code front qui permet de faire un upload multipart vers un serveur. Il y a un peu de logique métier custom, par exemple ImportCoinmarketcapFileMultipartStreamArg est une structure métier propre à l'app d'origine, mais je pense que tu arriveras à comprendre le principe. Je ne te fournirai pas le code back-end, mais saches qu'il s'agit d'un projet Next.js avec des server actions, mais ça n'a pas grande importance car nous on va chercher à abstraire toute cette logique pour faire une lib générique, et utilisable peu importe le contexte d'utilisation : back-end node, front avec vanilla JS, front avec React ou autre framework, etc. Nous on reste agnostique et la lib ne s'occupe pas de savoir si elle tourne dans du node, dans du browser, ou si elle est appelée par un framework, SAUF cas spécifique (par exemple le check de l'utilisation du CompressionStream, aussi dispo sur node, mais là on fait le check sur window alors que dans node il n'existe pas d'objet window - explorer globalThis ?)

À partir de ce code, crée une lib JavaScript/TypeScript npm full-stream et chunked pour l’upload de fichiers, compatible S3/Minio, modulaire et tree-shakable. Modernise et rends le code plus robuste, fiabilise la logique, et rends-le extensible avec une architecture de pipeline pour transformations ou compression côté client. Utilise la lib typescript `effect` (https://effect.website/, https://github.com/Effect-TS, https://www.npmjs.com/package/effect) pour gérer l’orchestration async, les retries, les aborts et la gestion des erreurs. Fournis un exemple minimal montrant un upload d’image vers S3/Minio avec un middleware de compression, et montre comment intégrer la librairie dans un projet web. La librairie doit être prête à packager et publier sur npm, avec TypeScript types, modules ES, et tree-shaking supporté.

J'ai cloné effect (ici : @effect/) pour que tu puisses facilement accéder à son README pour comprendre l'ampleur de ce que ça permet de faire, à moins que tu ne le saches déjà.
